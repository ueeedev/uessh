## 新功能

### 工作台与标签页
- 整个软件变成一条标签栏：第一个标签固定为「工作台」（主机、密钥、片段、端口转发、设置），后面是 SSH 标签页；原来单独的「终端」页面已去掉
- 标签栏高度调小，与 macOS 红绿灯按钮居中对齐
- Windows 上使用软件自绘的标题栏和窗口按钮
- 双击标签栏空白处可最大化或还原窗口；按住空白处可拖动窗口
- 拖动标签页可调整顺序
- `⌘1`–`⌘9`（Windows 为 `Ctrl+1`–`Ctrl+9`）切换标签页：`1` 是工作台，`9` 是最后一个

### 分屏工作区
- 把 SSH 窗口或标签页拖到另一个窗口的上、下、左、右，即可组成分屏工作区（类似 Termius 的工作台）
- 可拖动分隔线调整大小，也可一键等分
- 单个窗格可放大，可将窗格拆分成独立标签
- 支持「广播输入」：同一工作区内的所有窗格同时输入
- 合并后的工作区默认名为「工作区 1」，点击标签可重命名

### AI 助手
- SSH 页面右侧按钮栏新增 AI 侧边栏
- 支持的服务商：Anthropic Claude、OpenAI、DeepSeek、Gemini、Grok，以及兼容 OpenAI 接口的自定义服务商
- 在设置中先选择服务商，再填写对应的 Key；Key 加密保存在本机保险库中
- 输入框可切换模型
- AI 可以在当前服务器上执行命令、读取终端内容。权限分四档：
  - 关闭
  - 每次询问
  - 只读命令自动执行（默认）
  - 全部允许（红色并带警告，开启前会再确认一次）
- AI 执行的命令及其输出会实时显示在 SSH 窗口里，前后有分隔线标记
- 每台服务器的 AI 对话都有历史记录，加密保存

### 文件浏览器（SFTP）
- 右侧按钮栏新增文件按钮，在 SSH 窗口底部打开文件浏览器
- 自动跟随终端当前所在目录
- 四种显示方式：图标、列表、分栏、画廊（参考 macOS 访达）
- 上传方式：
  - 在文件夹上右键上传
  - 点击工具栏按钮上传
  - 把文件拖到文件浏览器里
  - 把文件拖到 SSH 窗口上，会出现「松开上传到此路径」的提示
- 支持下载、新建文件夹、显示隐藏文件
- 运行命令后文件列表在后台安静刷新，不再闪烁

### 连接
- **断线自动重连**：SSH 连接意外断开后自动重连，默认最多 3 次、每次间隔 3 秒
  - 可在「设置 → SSH 连接」中关闭，或修改次数和间隔
  - 输入 `exit` 正常退出不会触发重连
  - 等待重连时，终端顶部显示倒计时，可「立即重连」或「取消」
- **命令语法高亮**：在终端里为正在输入的命令着色，只在本机显示，不改动服务器
  - 着色内容：命令、危险命令（如 `rm`、`dd`、`mkfs`）、选项、字符串、变量、管道/重定向、注释
  - 每种颜色都可在设置中自定义
  - 如果服务器已经自带高亮（zsh-syntax-highlighting、fish），会保留服务器的颜色

### 主机
- 主机卡片：单击选中，双击连接

## 改进与修复
- 修复：在 macOS 上点窗口的关闭按钮，后台也会一起退出
- 修复：服务器拒绝设置环境变量（`SSHChannelRequestError … LC_UESSH_SESSION`）时无法连接
- 修复：单击主机卡片或文件时，有约 0.3 秒的点击延迟
- macOS 菜单栏图标改为新的猫咪剪影
- 设置页不再显示构建号
