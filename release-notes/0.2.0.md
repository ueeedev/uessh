## 新功能

### 洋葱连接（多跳 SSH 链式跳转）
- **可视化洋葱连接管理页**：在侧边栏新增「洋葱连接」页面，支持创建与保存多跳 SSH 链路卡片（如 `A → B → C`）；卡片直观展示总跳数、完整跳转链路、备注或等效 `ssh -J` 命令预览（支持一键复制）与搜索筛选，点击卡片或「连接」按钮即可建立多跳终端会话
- **链式节点编排与主机卡片选择器**：
  - 在新建/编辑侧边抽屉中可可视化配置 **本机 → 多个中间节点 → 结束节点**，支持自由新增任意数量中间节点、上移/下移调整跳转顺序、更换或移除节点，并实时提示隐私可见性（如「目标节点 C 仅可见来自 B 的 SSH 连接」）与等效 `ssh -J` 命令
  - 新增中间节点或选择结束节点时，弹出与主机页面风格一致的**主机卡片网格选择器**，支持按分组展示、在线状态点、头像与关键词搜索，并标注「已在链路中」的节点
- **端到端逐跳加密隧道引擎**：
  - 基于 SSH `direct-tcpip`（`forwardLocal`，等效 OpenSSH `ProxyJump`）逐跳建立加密连接，终端实时输出逐跳连接与转发进度，复用每台主机的密钥、密码、主密码保险库与 `known_hosts` 指纹校验
  - 首跳支持自动接入设置的 SSH 网络代理；断开、失败或中途取消时按逆序安全关闭所有中间跳板连接；连上最终节点后，终端、SFTP 文件浏览、系统信息、AI 助手与代码片段均无缝作用于目标服务器，标签页同步展示洋葱层级图标与悬停完整路径提示

### 网络代理设置（AI 网络代理 & SSH 网络代理）
- **独立拆分 AI 与 SSH 代理配置**：在设置页新增「网络代理」分区，将 **AI 网络代理**（用于 AI 助手对话与模型列表拉取，默认跟随系统）与 **SSH 网络代理**（用于 SSH 终端连接、洋葱连接首跳与端口转发隧道，默认直连）分开独立配置
- **支持跟随系统 / 直连 / 自定义 HTTP 与 SOCKS5**：
  - 实时显示自动检测到的系统代理地址（支持 macOS `scutil --proxy` 与 Windows 注册表中的 HTTP/HTTPS 及 SOCKS 代理）
  - 自定义模式支持 **HTTP CONNECT** 与 **SOCKS5**（RFC 1928 / 1929），支持可选用户名/密码认证（代理密码仅存入加密主密码保险库，不写入明文配置文件）
  - 内置「测试连接」按钮，可一键验证当前配置的代理连通性与握手状态

## 改进

- **设置页左侧竖向二级菜单与关于页**：将「通用」「外观」「在线检测」「SSH 与终端」「网络代理」「AI 助手」「MCP 服务」「安全」「诊断」「关于」重构为设置页左侧竖向排布的二级导航菜单，点击分类即可直接切换右侧对应配置面板；新增「关于」页面居中展示应用图标、软件名称、版本号与检查更新入口
- **双语与测试覆盖**：补全洋葱连接与网络代理设置的全部中英文界面本地化文案，新增洋葱多跳链式连接（含逆序清理、取消及主机卡片选择器 UI 流程）、设置页二级菜单交互与 HTTP CONNECT / SOCKS5 本地回环传输自动化测试
