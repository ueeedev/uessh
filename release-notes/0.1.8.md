## 新功能

### 代码片段（Snippets）与内置代码编辑器
- **代码片段管理页**：在工作台「片段」页集中管理常用命令与多行脚本，支持 **Shell (`sh`)**、**Bash**、**Python**、**PowerShell**、**Node.js** 与 **纯文本**，支持按语言、分组筛选与关键词搜索，可一键复制、编辑或直接发送到当前活跃终端运行
- **浏览器标签页式代码编辑器**：
  - 新建或编辑代码片段改为在主窗口顶部标签栏中以新标签页打开，标签页左侧通过 `|` 分隔线清晰区分 SSH 终端标签页与代码编辑器标签页
  - 支持同时打开多个代码片段标签页，在工作台、SSH 终端与编辑器标签页间切换时完整保留未保存草稿，支持 `⌘/Ctrl + S` 快捷保存、`⌘/Ctrl + W` 关闭（未保存时弹窗确认）与 `⌘/Ctrl + 1~9` 标签页切换
  - 左侧为类 VS Code 风格代码编辑器：提供多语言实时语法高亮（深色 Dark+ / 浅色 Light+ 主题自适应）、同步滚动行号槽、`Tab` / `Shift + Tab` 缩进与反缩进、回车智能自动缩进、中文输入法组字兼容，以及底部状态栏（`Ln/Col`、选中字符数、缩进空格数、编码与语言）
  - 右侧为代码片段信息面板：支持填写名称、脚本类型、分组（含已有分组快捷选择）、说明，自动识别 `{{变量名}}` 占位符并展示运行方式说明，底部固定提供「从文件导入」「删除」「取消」「保存」操作按钮
- **终端右侧代码片段面板**：在终端右侧工具栏新增代码片段侧栏开关，可边看终端边搜索代码片段，一键「运行」或「填入终端」；多行脚本（`sh` / `bash` / `python` / `node`）自动通过防冲突 heredoc（或 Windows PowerShell here-string）安全执行，不在服务器留下临时文件；含 `{{参数}}` 占位符的片段运行时自动弹窗填写参数

### 端口转发（Port Forwarding）
- **完整支持三种 SSH 转发模式**：
  - **本地转发（`-L`）**：监听本地端口并通过 SSH 隧道转发至远程目标服务（如内网数据库、Web 管理后台）
  - **远程转发（`-R`）**：在远程 SSH 服务器监听端口，将访问回连至本机或本地局域网服务
  - **动态转发（`-D`）**：在本地启动内置 SOCKS5 代理，通过 SSH 服务器动态转发任意目标流量
- **独立可靠的隧道运行与监控**：
  - 转发隧道复用已保存主机的密码、密钥、主密码保险库与 `known_hosts` 主机指纹校验，且独立于终端标签页运行，关闭终端不会中断活跃隧道
  - 实时展示隧道运行状态、活跃连接数与上下行流量（`↑ / ↓`），侧边导航栏「转发」入口实时显示运行中隧道数量徽章
  - 支持「连接主机时自动启动」、一键「全部停止」、一键复制监听地址、按类型 / 运行状态筛选与搜索，以及编辑抽屉内的 `127.0.0.1` / `0.0.0.0` 快捷填写与实时等效 `ssh -N -L/-R/-D` 命令预览
