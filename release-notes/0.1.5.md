## 新功能

### 本地终端
- 工作台侧边栏「设置」上方新增「本地终端」按钮，点击后在新标签页打开本机的 shell
  - macOS 使用你的默认 shell（如 zsh），环境与系统「终端」一致
  - Windows 使用 PowerShell
- 和 SSH 标签页一样，支持分屏、拖成工作区、广播输入和命令高亮
- 右侧的 AI、文件、信息在本地终端里都针对本机生效：
  - AI 在本机执行命令（Windows 上每条命令都需要确认）
  - 文件浏览器浏览本机文件，macOS 上会跟随终端当前目录
  - 信息栏显示本机的系统版本、CPU、内存和磁盘

### 检查更新
- 设置页底部版本号下方新增「检查更新」
- 「设置 → 通用」新增「自动检查更新」开关（默认打开）：启动时自动检查，有新版本才提示
- 发现新版本时可以选择：下次再说、立刻前往 GitHub 下载、忽略此版本（之后有更新的版本再提示）

### 右侧展开栏分为上下两部分
- 上半部分是信息栏，下半部分是 AI 助手，可以同时打开
- 两部分中间的分隔线可以拖动调整高度，双击恢复各占一半；拖动左边缘时两部分一起调整宽度
- 右侧按钮栏重新排布：信息按钮在顶部，AI 和文件按钮在底部

## 改进

### AI 助手
- 回复完整支持 Markdown：表格、各种列表（含任务列表）、引用、分隔线、标题、*斜体*、~~删除线~~、链接；整条回复可以跨段落选中复制
- AI 在终端里执行命令时，会用带「UESSH AI」标题的边框标出所执行的命令
- 修复：切换 SSH 窗口后，AI 对话会跳回最上面。现在会回到离开时的位置
- 安全：
  - 回复里的链接要确认网址后才会打开，且只允许 `http` / `https`
  - 图片不会自动加载
  - HTML 不会被执行

### 界面
- 所有提示（复制成功、上传完成、检查更新结果等）从窗口底部改到右上角的提示卡片，带滑入、滑出动画；鼠标悬停时不会消失
- 上传进度卡片也移到了右上角
- 右侧按钮与面板、窗口边缘的间距调整为一致

## 其他变化
- **macOS 版不再使用 App 沙盒**（本地终端需要访问你的文件和命令）。首次启动 0.1.5 时会自动把原来的主机、密钥、设置等数据复制到新位置 `~/Library/Application Support/dev.ueee.uessh`，旧数据保留不动
- 新增 README 和贡献指引（[CONTRIBUTING.md](https://github.com/ueeedev/uessh/blob/main/CONTRIBUTING.md)）
