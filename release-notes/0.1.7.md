## 新功能

### 本地 MCP 服务器
- 「设置 → MCP 服务器」新增内置本地 MCP 服务器，允许本机外部 AI 客户端（如 Claude Code、Cursor、Codex、Antigravity 等）通过 MCP 调用 UESSH 操作服务器与本地终端
- 同时支持 **Streamable HTTP**（`POST /mcp`）与 **Legacy HTTP+SSE**（`GET /sse` + `POST /messages`）两种协议，仅监听 `127.0.0.1`（默认端口 `37821`，可自定义）
- 提供 5 个 MCP 工具：
  - `list_sessions`：列出当前打开的 SSH 与本地终端会话
  - `list_hosts`：列出已保存的主机基础信息（不暴露密码与私钥）
  - `open_session`：打开已保存主机或本地终端会话，默认可复用已连接会话
  - `run_command`：向指定或当前活跃终端发送指令并获取退出码与输出；执行过程会在终端内以「UESSH MCP」命令框实时显示并恢复提示符
  - `read_terminal`：读取终端最近的屏幕与回滚输出
- 安全与配置：
  - 访问令牌（Bearer Token）自动随机生成并加密保存在本机保险库中，支持查看、复制、重置，以及一键「复制 MCP 配置」JSON
  - 校验本机 `Host` 与 `Origin` 头（防御 DNS 重绑定与跨站请求），保险库锁定时自动拒绝所有调用
  - 支持三种安全确认策略：智能分级（默认：只读自动执行，修改/敏感命令弹窗确认）、每次弹窗确认、全部自动执行（带高风险提示）；确认弹窗会高亮提示隐藏或双向控制字符

### 文件浏览器
- 在文件夹右键菜单及当前目录空白处右键菜单新增「在此位置新建窗口」，新建终端标签页后自动进入对应目录（远程 SSH 自动执行安全转义的 `cd`，本地终端直接以该目录作为工作目录启动）

## 改进

### 终端右键菜单
- 终端右键菜单顶部改用单行三图标操作栏展示「复制」「粘贴」「清屏」，点击「清屏」清空屏幕与历史回滚并保留当前提示符行

## 修复

- **中文输入法**：修复终端无法使用中文输入法（IME）输入中文、只能输入英文字符的问题；放行普通可打印字符键进入系统输入法组字流程，同时保持方向键、控制键与各类快捷键行为不变
- **macOS 最小化恢复**：修复 macOS 上按 `Cmd + M` 最小化窗口后点击程序坞图标无法展开窗口的问题（移除对 `FlutterAppDelegate` 未实现方法的 `super` 调用，补全 `deminiaturize` 还原逻辑，并在展开后重新校准左上角窗口按钮位置）
