## 改进

### 右侧信息栏

- 使用 Material Design 3 次级标签，将信息栏分为「基础信息」「性能分析」「磁盘分析」「任务进程」四页
- 基础信息展示主机名、系统和内核，系统名称后显示对应的 Windows、macOS 或 Linux 图标
- 性能分析使用同排两列的 Material Design 3 紧凑圆形指示图展示 CPU 和内存占用，采用无卡片背景布局
- 磁盘分析展示本地挂载文件系统的容量、已用空间和可用空间
- 任务进程按 CPU 使用率排序，最多展示 50 个进程，包含 PID、进程名、CPU 和内存占用
- 支持每 5 秒自动刷新和手动刷新，刷新失败时保留上次数据并提示
- 切换会话和断线重连时重新采集，避免显示旧会话的数据
- 支持中英文、浅色与深色主题，以及窄面板下的横向标签滚动
- 修复调整上下侧栏高度时触发的界面刷新报错
